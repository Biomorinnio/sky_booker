#### 2.2 Доменная модель

**Основные сущности:**

1. **Flight (Рейс)**

   - Описание: Авиарейс с информацией о маршруте
   - Атрибуты: номер рейса, авиакомпания, маршрут, время
   - Связи: имеет множество тарифов (Fare)

2. **Fare (Тариф)**

   - Описание: Ценовое предложение для рейса
   - Атрибуты: тип, цена, условия, багаж
   - Связи: принадлежит рейсу (Flight)

3. **Booking (Бронирование)**

   - Описание: Заказ на перелет
   - Атрибуты: PNR, пассажиры, статус, цена
   - Связи: связано с рейсом и тарифом

4. **Passenger (Пассажир)**

   - Описание: Информация о пассажире
   - Атрибуты: ФИО, документ, контакты
   - Связи: входит в бронирование

5. **Payment (Платеж)**
   - Описание: Платежная транзакция
   - Атрибуты: сумма, метод, статус
   - Связи: связан с бронированием

**ER-диаграмма:**

```
┌──────────┐       ┌──────────┐       ┌──────────┐
│  Flight  │──1:N──│   Fare   │       │ Passenger│
└──────────┘       └──────────┘       └──────────┘
     │                  │                   │
     │                  │                   │
     └────────1:N───────┴────────N:M────────┘
                        │
                   ┌──────────┐
                   │ Booking  │
                   └──────────┘
                        │
                        │1:1
                        │
                   ┌──────────┐
                   │ Payment  │
                   └──────────┘
```

## 💡 Типичные вопросы на защите

### Технические вопросы

**Q: Почему выбран Next.js, а не чистый React?**
A: Next.js предоставляет SSR, оптимизацию производительности, встроенную маршрутизацию и лучшее SEO из коробки.

**Q: Как обеспечивается безопасность данных?**
A: Валидация на клиенте и сервере, HTTPS, защита от XSS и CSRF, шифрование чувствительных данных.

**Q: Как масштабируется приложение?**
A: Модульная архитектура, разделение на компоненты, возможность горизонтального масштабирования backend.

**Q: Как обрабатываются ошибки?**
A: Try-catch блоки, error boundaries в React, логирование ошибок, user-friendly сообщения.

### Бизнес-вопросы

**Q: Какие преимущества у вашего решения?**
A: Современный UI/UX, быстрая работа, адаптивность, простота использования.

**Q: Кто целевая аудитория?**
A: Пользователи, бронирующие авиабилеты онлайн (18-65 лет, средний и выше средний доход).

**Q: Как монетизировать проект?**
A: Комиссия с бронирований, реклама, премиум-функции, партнерские программы.
