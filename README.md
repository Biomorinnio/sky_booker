# ✈️ SkyBooker — Информационная система авиакомпании

Дипломный проект. Веб-приложение для автоматизации работы авиакомпании: управление рейсами, бронирование билетов, оплата, личный кабинет пассажира и панель сотрудников.

Стек намеренно простой — PHP без фреймворков на бэке и Next.js на фронте. Хотел показать, что понимаю как работает HTTP и REST, а не просто умею подключать Laravel. MySQL в качестве СУБД, ORM нет — все запросы через PDO вручную.

---

## 🗂 Структура репозитория

```
sky-booker/
├── backend/    # REST API на PHP 8+ (PDO, без фреймворков)
└── frontend/   # Next.js 15, TypeScript, Tailwind CSS
```

Подробный запуск — в README каждой части.

---

## ⚙️ Быстрый старт

**Бэкенд:**
```bash
cd backend
# настроить config/db.php, накатить schema.sql
php -S localhost:3001 router.php
```

**Фронтенд:**
```bash
cd frontend
npm install
npm run dev
```

Открыть: [http://localhost:3000](http://localhost:3000)

## 🧩 Что реализовано

| Модуль | Описание |
|--------|----------|
| 🔐 Аутентификация | JWT (access + refresh), bcrypt, роли: passenger / agent / employee / admin |
| ✈️ Рейсы | CRUD для сотрудников, поиск по маршруту и дате для пассажиров |
| 🎫 Тарифы | Economy / Comfort / Business, настраиваемый багаж и условия |
| 📋 Бронирования | Создание, отмена (с возвратом 90%), статусы |
| 💳 Оплата | Смена статуса брони на `confirmed`, генерация транзакционного ID |
| 🎟 Электронные билеты | Автогенерация номера `TKTxxxxxxxx` при бронировании |
| 👤 Личный кабинет | История бронирований, смена пароля, профиль |
| 🏢 Панель сотрудника | Управление рейсами, статистика, топ маршрутов |
| 🌟 Программа лояльности | Начисление баллов (1 балл / 100 ₽), тиры bronze→platinum |

---

## 🛠 Технологии

**Backend**
- PHP 8.1+, PDO, bcrypt, HMAC-SHA256 (самописный JWT)
- MySQL 8.0, schema + seed в одном `schema.sql`

**Frontend**
- Next.js 15 (App Router), React 19, TypeScript
- Tailwind CSS, Radix UI, Lucide icons
- next-themes (light/dark)

## 👥 Роли пользователей

| Роль | Доступ |
|------|--------|
| `passenger` | поиск, бронирование, оплата, личный кабинет |
| `agent` | то же + расширенный просмотр бронирований |
| `employee` | панель управления, управление рейсами и тарифами |
| `admin` | полный доступ |
